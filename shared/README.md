# EduZim Shared Libraries

Reusable modules shared across all EduZim microservices.

## Modules

- `eduzim_shared.logging` — Structured JSON logging
- `eduzim_shared.errors` — Standardized error responses & exception handlers
- `eduzim_shared.kafka` — Kafka producer/consumer wrappers

## Installation

From any service:
```bash
pip install -e ../../shared
```
